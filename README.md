
🥬 MarulArsenal v2.9 — Siber Cephanelik Müdürü 🏹
MarulArsenal, siber güvenlik meraklıları, etik hackerlar ve sistem yöneticileri için geliştirilmiş, terminal tabanlı interaktif bir Siber Güvenlik Araç Yöneticisi ve Otomasyon Framework'üdür. Siber güvenlik dünyasında en çok kullanılan 50 popüler aracı tek bir çatı altında toplar. Araçları internette arama, repolarını kopyalama ve çalıştırma komutlarını hatırlama derdine son verir! Sizin yerinize araçları orijinal kaynaklarından indirir, kategorize eder ve akıllı motoru sayesinde tek tuşla terminalinizden çalıştırır. 🤖⚡

🚀 Öne Çıkan Özellikler
📂 Geniş Araç Cephaneliği: Nmap'ten Sqlmap'e, Sherlock'tan Phishing araçlarına kadar tam 50 adet güncel ve popüler araç hazır tanımlıdır.

🧠 Akıllı Çalıştırma Motoru (os.walk): İndirilen klasörlerin derinliklerini otomatik tarayarak .py, .sh, .bat, .ps1 veya .exe uzantılı çalıştırılabilir ana dosyaları tespit eder ve çalıştırma seçeneği sunar.

🔍 Gelişmiş Filtreleme ve Kategori Sistemi: Araçları kalabalık içinde aramayın! Keşif (Recon), Sızma (Exploitation), WiFi/Ağ Saldırıları gibi kategorilere göre filtreleyin.

🌐 Çapraz Platform ve Git Bash Desteği: Windows (Git Bash entegrasyonu ile) ve Linux üzerinde scriptleri sorunsuz yürütebilir.

🛡️ Derlenmiş Araç Koruması: Go, Rust veya C++ ile yazılmış (derlenmesi gereken) araçlarda kaynak kod karmaşasını önler, kullanıcıyı doğrudan resmi indirme sayfalarına yönlendirir.

🛠️ Kurulum ve Kullanım
Projeyi çalıştırmak son derece basittir. Terminalinizi açın ve aşağıdaki adımları takip edin:

Bash
# 1. Depoyu bilgisayarınıza klonlayın
git clone https://github.com/kullaniciadi/MarulArsenal.git

# 2. Proje klasörüne giriş yapın
cd MarulArsenal

# 3. Siber cephaneliğinizi başlatın!
python marul_exe_tools.py
📊 Cephanelik Kategorileri
Program içerisindeki araçlar siber saldırı ve savunma hatlarına göre titizlikle ayrılmıştır:

🕵️‍♂️ Keşif (Recon & OSINT): Hedef hakkında bilgi toplama, subdomain ve gizli dizin tarama araçları.

⚔️ Sızma (Exploitation): Zafiyet tespiti, otomatik SQL enjeksiyonları ve exploit yönetim frameworkleri.

📶 WiFi & Ağ Saldırıları: Kablosuz ağ analizleri, sahte erişim noktası (Evil Twin) ve MITM araçları.

💣 Stres Testleri (DoS/DDoS): Altyapı ve ağ yük kapasitesini test eden mekanizmalar.
